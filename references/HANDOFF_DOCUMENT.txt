一、交接摘要
目前交付的是「可執行的課程 PoC」，不是已可上線的企業產品。核心 A（決策前風險分析）已有程式化原型；B（跨層依賴追蹤）與 C（模擬事件提醒）有初版。系統預設使用合成研發資料，不包含真實企業資訊。

二、不可改掉的設計原則
•  人工是決策主體：Agent 可質疑、追問、推演，但不能越過管理者核准改動任務或通知第三人。
•  數學計算、單位檢核、權限、資料版本與動作許可由確定性程式處理，不靠 LLM 自行判定。
•  已知事實、合理推論、假設、未知必須分開；缺資料不能猜測啟動電流、溫升、交期或必然故障。
•  企業文件預設地端；未分類或機密內容不得外送雲端。使用者／專案／來源權限要在檢索前檢查。
•  本企劃學期內採單一 Agent；若擬改成多 Agent，需先讓使用者確認需求變更。

六、已完成的驗證與不可誤解的數據
以原開發環境留下的 VALIDATION_SUMMARY.md 為依據：Python 3.13／FastAPI 0.128.2 執行 37 項自動化測試通過；網頁實際完成登入、分析與建立待審核申請。這些驗證不代表正式環境一定可直接部署。
•  合成案例：PS-01 電源 24 V / 10 A；馬達 M-02 8 A；其他負載 3 A。合計 11 A、264 W；超過連續額定 10 A、240 W，判定指定條件不合格，但不能宣稱「設備必然跳脫」。
•  固定 12 案：已登錄的直接依賴路徑召回 11/45（24.44%）；多層依賴 45/45（100%），精確率 45/45（100%）。這是圖遍歷正確性，不是 LLM 工程推理成績。
•  安全邊界測試涵蓋：未授權存取、撤權後已存結果拒讀、來源版本失效、錯誤單位、循環圖、未核准寫入、過期核准、冪等與事件去重。
七、本機啟動與驗收
先將 ZIP 解壓縮，在 CrossDomainRiskAgent 目錄開啟終端機；使用 Python 3.12 或 3.13：
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m scripts.init_demo
python -m uvicorn app.api:app --host 127.0.0.1 --port 8000
瀏覽器開啟 http://127.0.0.1:8000。登入 Token 由初始化建立，保存在 runtime/demo_credentials.json；請勿將 Token 公開。
測試命令：
python -m pytest -q
python -m scripts.evaluate
八、Podman（教授要求）：必須實機再驗證
企劃要求 LLM server 以外的介面、Agent、檢索、工具、紀錄服務都由 Podman 容器運作。v0.1 已包含 Containerfile、compose.yml，但本次無法對外下載 image / 依賴，尚未成功實際建置驗證。
podman machine init           # 首次使用才執行
podman machine start
podman compose up --build -d
podman compose exec riskscope cat /app/runtime/demo_credentials.json
若 podman compose 無法使用，請看 ZIP 內 README.md 的 podman build / run 備用方式。請先核對 Podman 是否安裝、machine 是否啟動與 compose provider 是否可用。
九、最基本人工驗收順序
•  管理者登入 → 馬達負載分析 → 確認 11 A、264 W 與方案 A 被阻擋。
•  查看 M-02 的工程影響路徑，確認有來源與版本資訊。
•  提出模擬 TEST-01 變更 → 核准前不可執行 → 核准後才可模擬執行。
•  模擬供應商交期變更，確認重新分析、內部提醒與同一事件 ID 去重。
•  使用 engineer、outsider 身分重測權限；修改文件後重測舊分析及舊核准。

十一、已知限制與續作警示
•  Podman、LangGraph StateGraph 路徑、實際 Ollama／Qwen3 尚未在原環境完成端到端驗證。LangGraph 不可用時會明示 sequential_fallback。
•  Demo Token + SQLite 不等同企業級認證、審計不可竄改或完整多使用者資料隔離；預設限本機，不要直接公開至網際網路。
•  LLM 可補充文字，但工程數值判斷、存取規則與模擬寫入均不能被 LLM 覆寫。
•  事件為手動送出的合成更新，並非真正持續監控；尚無真實第三方通知。
•  已標註的工程依賴圖不是任意新產業的自動專業推理，不應誇大跨領域能力。
